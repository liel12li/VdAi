# 🎬 VdAi — מחולל סרטוני Reels פרסומיים

תוכנה שמקבלת עמוד אינסטגרם של עסק (או תיקיית תמונות/סרטונים) ומייצרת
**כמה סרטוני Reels פרסומיים מוכנים לפרסום** — עם הוק פותח, טקסטים על
המסך, מעברים, מיתוג, קריאה לפעולה, מוזיקת רקע, **קריינות אוטומטית עם
כתוביות מסונכרנות**, וגם **קופי והאשטגים מוכנים לפוסט**.

תמיכה מלאה בעברית (RTL) ובאנגלית.

## ✨ מה התוכנה עושה

1. **ניתוח העסק** — מורידה מהפרופיל באינסטגרם את הביו, תמונת הפרופיל
   והפוסטים האחרונים (או משתמשת בתיקייה מקומית). עם `vdai login` היא
   גולשת עם החשבון שלכם — יציב יותר, וכולל פרופילים פרטיים שאתם עוקבים
   אחריהם.
2. **קונספטים עם Claude** — מודל ה-AI **רואה את התמונות עצמן** (vision)
   וכותב כמה קונספטים שונים: הוק, טקסטים לכל סצנה, CTA, קופי לפוסט,
   האשטגים ותסריט קריינות — בטון המותג שתבחרו. (בלי מפתח API התוכנה
   עובדת עם תבניות מובנות.)
3. **קריינות** — או שתקליטו בעצמכם (יתומלל עם Whisper), או שתדליקו
   `--tts` והתוכנה תקריא את התסריט בקול עברי טבעי (חינם, ללא מפתח) —
   הכתוביות מסונכרנות אוטומטית מילה-במילה.
4. **רינדור** — תנועת מצלמה על תמונות (Ken Burns), חיתוך וידאו, שכבות
   טקסט, מעברים, פס התקדמות, צבע מותג אוטומטי (או מערכת המותג שלכם),
   ווטרמרק וכרטיס סיום עם לוגו ו-CTA.
5. **מוכן לפרסום** — לכל סרטון: תמונת קאבר, קובץ קופי+האשטגים, SRT,
   והכל ארוז ב-zip אחד עם `--package`.

## 🚀 התקנה והפעלה (חשוב!)

דרישות: Python 3.10+ (אין צורך להתקין ffmpeg — מגיע אוטומטית).

**שלב 1 — התקנת הספריות (פעם אחת):** פותחים טרמינל בתיקיית הפרויקט ומריצים:

```bash
pip install -r requirements.txt
```

**שלב 2 — הפעלה:** מריצים את הקובץ **`run.py`** (לא קבצים אחרים!):

```bash
python run.py            # פותח את האפליקציה כחלון
python run.py web        # ממשק ווב בדפדפן
```

> 💡 **ב-VS Code:** פתחו את `run.py` ולחצו על הכפתור הירוק ▶. **אל תריצו את
> הקבצים שבתוך תיקיית `vdai/`** (כמו `cli.py`) ישירות — הם חלק מחבילה ולכן
> ייתנו שגיאת `attempted relative import`. תמיד מריצים את `run.py`, או
> `python -m vdai` מתיקיית הפרויקט.
>
> **דאבל-קליק:** ב-Windows יש את `הפעלה-VdAi.bat`, ב-Mac את
> `start-VdAi.command` — דאבל-קליק עליהם פותח את האפליקציה ישר.

**מפתח Claude (מומלץ):** `export ANTHROPIC_API_KEY=sk-ant-...` (ב-Windows:
`set ANTHROPIC_API_KEY=sk-ant-...`). בלעדיו התוכנה עובדת עם תבניות מובנות.

## 🔐 חיבור חשבון אינסטגרם (מומלץ)

```bash
python -m vdai login my_username     # סיסמה + קוד אימות דו-שלבי אם מופעל
python -m vdai login --check         # האם החיבור עדיין תקף?
python -m vdai logout                # ניתוק ומחיקת הסשן מהמחשב
```

- **הסיסמה לא נשמרת לעולם** — רק עוגיות הסשן, בקובץ מקומי עם הרשאות
  owner-only, מחוץ ל-git. קובץ הסשן שקול לגישה לחשבון — לא לשתף.
- אם אינסטגרם דורש אישור ("checkpoint"), אשרו באפליקציה ונסו שוב.
- בלי חיבור התוכנה עובדת במצב אנונימי על פרופילים ציבוריים.

## 🖥️ אפליקציה על שולחן העבודה

```bash
python -m vdai desktop            # פותח את VdAi כחלון אפליקציה
python -m vdai install-desktop    # שם אייקון של VdAi על שולחן העבודה
```

`install-desktop` יוצר קיצור דרך עם האייקון של VdAi (Windows ‎.lnk‎ /
macOS ‎.command‎ / Linux ‎.desktop‎ + תפריט האפליקציות) — לחיצה כפולה
פותחת את התוכנה כמו כל אפליקציה. אותה התקנה זמינה גם מכפתור
**"📥 התקנה על שולחן העבודה"** בתוך הממשק עצמו.

לחלון נייטיב לגמרי (בלי דפדפן): `pip install pywebview` — והתוכנה
תזהה ותשתמש בו אוטומטית. בנוסף, הממשק הוא PWA — בדפדפני Chrome/Edge
יופיע גם כפתור "התקנת אפליקציה" בשורת הכתובת.

## 🌐 ממשק ווב

```bash
python -m vdai web        # → http://127.0.0.1:8000
```

טופס בעברית: עסק או העלאת קבצים, פורמט, טון, קריינות אוטומטית, מצב
טיוטה — ומקבלים סרטונים + קאבר + חבילת פרסום להורדה.

## ⌨️ שימוש משורת הפקודה

```bash
# 3 סרטונים מפרופיל אינסטגרם
python -m vdai generate cafe_dizengoff --count 3

# עם קריינות אוטומטית (Claude כותב, התוכנה מקריאה) וחבילת פרסום
python -m vdai generate cafe_dizengoff --tts --package

# קריינות שהקלטתם בעצמכם — תתומלל ותוטמע ככתוביות
python -m vdai generate cafe_dizengoff --voiceover voice.mp3

# כמה פורמטים בבת אחת + טון יוקרתי + ערכת מותג
python -m vdai generate cafe_dizengoff --format reel,square --tone luxury --brand brand.json

# טיוטה מהירה לבדיקת כיוון, רינדור מקבילי
python -m vdai generate cafe_dizengoff --draft --jobs 3

# מתיקייה מקומית (בלי אינסטגרם בכלל)
python -m vdai generate --media-dir ./photos --name "מספרת דנה" --bio "מספרה בוטיק"
```

זרימת עריכה בשני שלבים — לשליטה מלאה בטקסטים:

```bash
python -m vdai generate cafe_dizengoff --concepts-only          # שלב 1: קובץ JSON לעריכה
# עורכים את outputs/cafe_dizengoff_concepts.json
python -m vdai generate cafe_dizengoff --from-concepts outputs/cafe_dizengoff_concepts.json
```

תמלול עצמאי:

```bash
python -m vdai transcribe voice.mp3 --srt voice.srt
python -m vdai transcribe interview.mp4 --burn interview.mp4 --out captioned.mp4 --caption-style bold
```

## 🎛️ אפשרויות עיקריות ב-generate

| דגל | מה הוא עושה |
|---|---|
| `--count N` | כמה קונספטים/סרטונים |
| `--format reel,square,portrait,wide` | 9:16 / 1:1 / 4:5 / 16:9, אפשר כמה יחד |
| `--tts` + `--tts-gender female/male` | קריינות אוטומטית עם כתוביות מסונכרנות |
| `--voiceover file` | קריינות מוקלטת (תמלול Whisper) |
| `--tone warm/luxury/energetic/young/professional` | טון הכתיבה |
| `--brand brand.json` | ערכת מותג: צבע, לוגו, CTA קבוע, האשטגים, קול |
| `--caption-style pill/bold/minimal` | סגנון הכתוביות |
| `--draft` | חצי רזולוציה + רינדור מהיר, לבדיקת כיוון |
| `--package` | zip מוכן לפרסום: וידאו+קאבר+קופי+SRT |
| `--jobs N` | רינדור מקבילי |
| `--concepts-only` / `--from-concepts` | עריכת הטקסטים לפני הרינדור |
| `--no-vision` / `--no-ai` / `--no-progress-bar` | כיבוי יכולות |

ערכת מותג (`brand.example.json`):

```json
{
  "accent": "#C96F4A",
  "logo": "assets/logo.png",
  "cta": "שריינו תור עכשיו",
  "tone": "warm",
  "hashtags": ["#תלאביב"],
  "tts_voice": "he-IL-HilaNeural"
}
```

## 🎵 מוזיקה

מטעמי זכויות יוצרים לא מצורפת מוזיקה. שימו קבצים חוקיים ב-`assets/music/`
— התוכנה תבחר רצועה לפי מצב הרוח של הקונספט (אם שם הקובץ מכיל
`energetic` / `chill` / `elegant` / `uplifting`), או השתמשו ב-`--music`.

## ⚙️ הגדרות (משתני סביבה)

| משתנה | ברירת מחדל | תיאור |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | מפתח Claude API לקופי מותאם |
| `VDAI_IG_USER` / `VDAI_IG_PASSWORD` | — | חיבור אינסטגרם לאוטומציה (עדיף `vdai login`) |
| `VDAI_MODEL` | `claude-opus-4-8` | מודל Claude |
| `VDAI_WHISPER_MODEL` | `small` | גודל מודל תמלול (`tiny`…`large-v3`) |
| `VDAI_WIDTH` / `VDAI_HEIGHT` / `VDAI_FPS` | 1080 / 1920 / 30 | ברירת מחדל לוידאו |
| `VDAI_FONT` | פונט Heebo מצורף | נתיב לפונט ‎.ttf‎ אחר |
| `VDAI_OUTPUT_DIR` / `VDAI_MUSIC_DIR` | `outputs` / `assets/music` | תיקיות |

## 📝 הערות חשובות

- **אינסטגרם** — דרך [instaloader](https://instaloader.github.io/);
  השימוש באחריותכם ובכפוף לתנאי אינסטגרם — מומלץ על העסק שלכם או
  באישור בעל העסק. נחסמתם זמנית? חכו, או עבדו עם `--media-dir`.
- **קריינות אוטומטית** — דרך שירות Edge TTS החינמי של מיקרוסופט (נדרש
  אינטרנט). קולות עבריים: `he-IL-HilaNeural` (נשי), `he-IL-AvriNeural` (גברי).
- **תמלול** — בהרצה הראשונה יורד מודל Whisper (כמה מאות MB).
- **פונט** — מצורף [Heebo](https://github.com/OdedEzer/heebo) (רישיון OFL).
- **זמן רינדור** — סרטון מלא נרנדר על המעבד, בדרך כלל 1–3 דקות; `--draft`
  יורד לשניות, `--jobs` מקביל.

## 🗺️ מפת דרכים

מתוכנן להמשך (לפי סדר ערך משוער):

- **פרסום ישיר לאינסטגרם** — חיבור Instagram Graph API (דורש חשבון
  עסקי + אפליקציית Meta) להעלאה ותזמון מתוך התוכנה.
- **לוח תוכן שבועי** — "תייצר לי תוכן לשבוע": סדרת סרטונים מתוזמנת
  עם זוויות שונות + דוח פרסום.
- **כתוביות קריוקי** — הדגשת המילה הנאמרת בזמן אמת.
- **גלריית היסטוריה בווב** — כל הסרטונים שנוצרו, חיפוש ושימוש חוזר.
- **מוזיקה חופשית מובנית** — אינטגרציה עם ספריות בחינם (Pixabay).
- **וידאו מתוך וידאו** — בחירת הרגעים הטובים בסרטוני המקור עם Claude.
- **אנליטיקה** — משיכת ביצועי הפוסטים בחזרה ולמידה איזה סגנון עובד.
- **קובץ התקנה עצמאי** — ‎VdAi.exe / ‎.dmg בלי צורך ב-Python בכלל
  (PyInstaller + בנייה אוטומטית ב-GitHub Releases).
- **אריזה כמוצר** — Docker, אתר התקנה, רישוי/מנויים.

## 🧱 מבנה הפרויקט

```
vdai/
├── cli.py               # שורת הפקודה
├── desktop.py           # אפליקציית שולחן עבודה: חלון + קיצורי דרך
├── pipeline.py          # הצינור המשותף: קונספטים → קריינות → רינדור → אריזה
├── packaging.py         # חבילות פרסום (zip)
├── config.py            # הגדרות ופורמטים
├── models.py            # מבני נתונים (פרופיל, קונספט, כתוביות, ערכת מותג)
├── instagram/
│   ├── fetcher.py       # הורדה מאינסטגרם + מצב תיקייה מקומית
│   └── auth.py          # חיבור חשבון: login, סשנים, 2FA
├── ai/
│   ├── creative.py      # קונספטים עם Claude (כולל vision) + תבניות גיבוי
│   └── tts.py           # קריינות אוטומטית עם כתוביות מסונכרנות
├── transcribe/engine.py # Whisper: תמלול, חלוקה לכתוביות, SRT
├── video/
│   ├── builder.py       # הרכבת הריל: סצנות, מעברים, פס התקדמות, אאוטרו
│   ├── captions.py      # צריבת כתוביות על וידאו קיים
│   ├── text.py          # רינדור טקסט עברי (RTL) עם Pillow
│   ├── effects.py       # Ken Burns, גרדיאנטים, צבע מותג
│   └── fonts.py         # איתור פונט עם תמיכה בעברית
└── web/                 # ממשק ווב (FastAPI)
```
