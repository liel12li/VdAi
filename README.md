# 🎬 VdAi — מחולל סרטוני Reels פרסומיים

תוכנה שמקבלת עמוד אינסטגרם של עסק (או תיקיית תמונות/סרטונים) ומייצרת
**כמה סרטוני Reels פרסומיים מוכנים לפרסום** — אנכיים (9:16, 1080×1920),
עם הוק פותח, טקסטים על המסך, מעברים, מיתוג, קריאה לפעולה, מוזיקת רקע,
וגם **קופי והאשטגים מוכנים לפוסט**.

בנוסף יש בה **תמלול**: מקליטים קריינות, התוכנה מתמללת אותה (Whisper)
ומטמיעה את הכתוביות בסרטון בסנכרון מלא — או צורבת כתוביות על וידאו קיים.

תמיכה מלאה בעברית (RTL) ובאנגלית.

## ✨ מה התוכנה עושה

1. **ניתוח העסק** — מורידה מהפרופיל הציבורי באינסטגרם את הביו, תמונת
   הפרופיל והפוסטים האחרונים (או משתמשת בתיקייה מקומית שתספקו).
2. **קונספטים עם Claude** — מודל ה-AI של Anthropic מנתח את העסק וכותב
   כמה קונספטים שונים: הוק, טקסטים לכל סצנה, CTA, קופי לפוסט והאשטגים.
   (בלי מפתח API התוכנה עובדת עם תבניות מובנות.)
3. **רינדור** — מנוע הווידאו מרכיב כל קונספט לסרטון: תנועת מצלמה עדינה
   על תמונות (Ken Burns), חיתוך סרטונים ל-9:16, שכבות טקסט, מעברים,
   צבע מותג שנדגם אוטומטית, ווטרמרק של העסק וכרטיס סיום עם CTA.
4. **קריינות וכתוביות** — אם מצרפים קובץ קריינות, התוכנה מתמללת אותו,
   מסנכרנת את אורך הסרטון לקריינות ומציגה כתוביות קצובות בסגנון ריל.

## 🚀 התקנה

דרישות: Python 3.10+ (אין צורך להתקין ffmpeg — מגיע אוטומטית).

```bash
git clone https://github.com/liel12li/VdAi.git
cd VdAi
pip install -r requirements.txt
```

מפתח API של Anthropic (מומלץ — זה מה שמייצר קופי מותאם לעסק):

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # או קובץ ‎.env‎ לפי ‎.env.example‎
```

## 🖥️ ממשק ווב (הכי נוח)

```bash
python -m vdai web
```

נפתח בכתובת <http://127.0.0.1:8000> — מזינים שם משתמש אינסטגרם או מעלים
קבצים, בוחרים כמה סרטונים, אפשר לצרף קריינות ומוזיקה, ומקבלים את
הסרטונים + הקופי להורדה ישירות מהדפדפן.

## ⌨️ שימוש משורת הפקודה

```bash
# 3 סרטונים מפרופיל אינסטגרם ציבורי
python -m vdai generate cafe_dizengoff --count 3

# מתיקייה מקומית (בלי אינסטגרם בכלל)
python -m vdai generate --media-dir ./photos --name "מספרת דנה" --bio "מספרה בוטיק בתל אביב"

# עם קריינות — תתומלל ותוטמע ככתוביות מסונכרנות
python -m vdai generate cafe_dizengoff --voiceover voice.mp3 --count 2

# עם מוזיקת רקע משלכם
python -m vdai generate cafe_dizengoff --music track.mp3

# ניתוח פרופיל בלבד (בלי רינדור)
python -m vdai analyze cafe_dizengoff
```

תמלול עצמאי:

```bash
# תמלול לקובץ כתוביות SRT
python -m vdai transcribe voice.mp3 --srt voice.srt

# צריבת כתוביות מתומללות על וידאו קיים
python -m vdai transcribe interview.mp4 --burn interview.mp4 --out interview_captioned.mp4
```

הפלט נשמר ב-`outputs/`: קובצי `.mp4` לכל קונספט + `*_concepts.json` עם
הקופי וההאשטגים של כל סרטון.

## 🎵 מוזיקה

מטעמי זכויות יוצרים לא מצורפת מוזיקה. שימו קבצי mp3/wav חוקיים בתיקייה
`assets/music/` — התוכנה תבחר רצועה לפי מצב הרוח של הקונספט (אם שם הקובץ
מכיל `energetic` / `chill` / `elegant` / `uplifting`), או השתמשו ב-`--music`.

## ⚙️ הגדרות (משתני סביבה)

| משתנה | ברירת מחדל | תיאור |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | מפתח Claude API לקופי מותאם |
| `VDAI_MODEL` | `claude-opus-4-8` | מודל Claude |
| `VDAI_WHISPER_MODEL` | `small` | גודל מודל תמלול (`tiny`…`large-v3`) |
| `VDAI_WIDTH` / `VDAI_HEIGHT` / `VDAI_FPS` | 1080 / 1920 / 30 | פורמט הווידאו |
| `VDAI_FONT` | פונט Heebo מצורף | נתיב לפונט ‎.ttf‎ אחר |
| `VDAI_OUTPUT_DIR` | `outputs` | תיקיית פלט |
| `VDAI_MUSIC_DIR` | `assets/music` | ספריית המוזיקה |

## 📝 הערות חשובות

- **אינסטגרם** — ההורדה עובדת על פרופילים **ציבוריים** בלבד, דרך
  [instaloader](https://instaloader.github.io/). אינסטגרם מגבילה בקשות
  אנונימיות; אם נחסמתם זמנית, חכו או עבדו עם `--media-dir`. השימוש
  באחריותכם ובכפוף לתנאי השימוש של אינסטגרם — מומלץ להריץ על עסק שלכם
  או באישור בעל העסק.
- **תמלול** — בהרצה הראשונה יורד מודל Whisper (כמה מאות MB למודל
  `small`). לעברית מומלץ `small` ומעלה.
- **פונט** — מצורף הפונט [Heebo](https://github.com/OdedEzer/heebo)
  (רישיון OFL) עם תמיכה מלאה בעברית.
- **זמן רינדור** — סרטון מלא (1080×1920) נרנדר על המעבד; בדרך כלל 1–3
  דקות לסרטון.

## 🧱 מבנה הפרויקט

```
vdai/
├── cli.py               # שורת הפקודה
├── config.py            # הגדרות
├── models.py            # מבני נתונים (פרופיל, קונספט, כתוביות)
├── instagram/fetcher.py # הורדה מאינסטגרם + מצב תיקייה מקומית
├── ai/creative.py       # קונספטים עם Claude + תבניות גיבוי
├── transcribe/engine.py # Whisper: תמלול, חלוקה לכתוביות, SRT
├── video/
│   ├── builder.py       # הרכבת הריל המלא
│   ├── captions.py      # צריבת כתוביות על וידאו קיים
│   ├── text.py          # רינדור טקסט עברי (RTL) עם Pillow
│   ├── effects.py       # Ken Burns, גרדיאנטים, צבע מותג
│   └── fonts.py         # איתור פונט עם תמיכה בעברית
└── web/                 # ממשק ווב (FastAPI)
```
